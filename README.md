# Library Manager

A simple Python program to manage a library's books and users.

## Features

- Add/Update/Remove books
- Add/Update/Remove members
- Borrow and return books
- Search books by title or author
- Track current loans
- View loan history per member
- Track available copies
- File storage using Books.txt, Members.txt and Loans.txt

## Versions

- v1.0.0 – First stable version with core functionality
- v2.0.0 – Added search functionality and loan history tracking
